# CrowPanel SCD41 Sensor Dashboard

SCD41 CO2センサによる空気質（CO2・温度・湿度）のリアルタイム監視とグラフ表示を提供するスマートモニタである．ハードウェアはESP32を搭載したCrowPanelを対象とする．
Wi-Fi設定，環境センサのダッシュボード，SDカードへのデータロギング，そしてメニュー画面といった複数画面機能を含む．

## 概要

CrowPanelのタッチスクリーンとLVGL（Light and Versatile Graphics Library）を活用したセンサ監視ダッシュボードである．
デバイス単体で周辺のWi-Fiアクセスポイントをスキャンしてインターネット経由で時刻同期を行い，Sensirion SCD41 CO2センサの計測データをリアルタイムに画面へプロットする．また，SDカードを用いたCSVデータのバックグラウンド記録により，過去のトレンド（4時間/24時間）の切り替え表示を可能にしている．設定した認証情報はESP32内に保存され，次回起動時は自動で再接続される．

## 画面構成と機能

4つのメイン画面で構成されている．

### 1. Wi-Fi設定画面
- **Wi-Fiスキャン機能**: ボタンをタップすると周辺のアクセスポイントを検索し，リストから接続したいSSIDを選択できる．
- **ソフトウェアキーボード**: スクリーンのキーボードで直感的にパスワードを入力可能である．

### 2. センサダッシュボード
- **環境データ表示**: SCD41センサから取得した現在のCO2濃度 (ppm)，温度 (℃)，湿度 (%)，および現在日時を表示する．
- **トレンドチャート**: ボタンで2つのモードを即座にシームレスに切り替え可能である．
  - **4Hモード**: 過去4時間分の詳細な推移を1分刻みで描画する．
  - **1Dモード**: 過去24時間分の推移を6分平均で描画する．
- **データ永続化と復元**: SDカードに日毎のログを自動記録し，起動時には過去の履歴を自動的に読み込んでグラフを復元する．

### 3. 手動日時設定画面
- **日時マニュアル設定**: ドラッグ操作で「年・月・日・時・分」を設定し，内部時計とSDへの記録時間を手動で設定できる．

### 4. メニュー画面
- 各種画面（Wi-Fi設定，日時設定，センサダッシュボード）へ遷移するためのナビゲーションメニューである．

## 初期設定と運用について

- **初回起動時**: 初回起動時はWi-Fiの設定を行うこと．これにより常に正しい時刻が表示され，ソフトウェアアップデート（OTA）機能も利用可能になる．
- **オフラインでの使用**: Wi-Fiを接続せずに使用するときは，手動で時刻設定を行なって使用する．ただし，電源を切断すると時刻情報が失われるため，その際は再度時刻設定をする必要がある（Wi-Fiを接続しているときは自動で時刻がセットされるので，この操作は不要）．

## 対応ハードウェア

| 機種 | 解像度 |
|------|--------|
| CrowPanel ESP32 2.4インチ | 320×240 |
| CrowPanel ESP32 2.8インチ | 320×240 |

- 拡張モジュール: **Sensirion SCD41 CO2センサ** (I2C)
- ストレージ: **MicroSDカード** (SPI通信)
- タッチコントローラ: **XPT2046**

## 依存ライブラリ

本プロジェクトはPlatformIO環境で構築されているため，必要なライブラリ群はビルド時に自動でダウンロード・インストールされる．

## セットアップ (PlatformIO)

### 1. プロジェクトの準備
本リポジトリをクローンまたはダウンロードし，VS Code等のPlatformIO環境で開く．

### 2. ライブラリ設定の配置
プロジェクトの `include/` ディレクトリ内に以下の2つの設定ファイルを配置すること．
- `User_Setup.h` (TFT_eSPI用のCrowPanelピン設定ファイル)
- `lv_conf.h` (LVGLのコンフィギュレーションファイル)

### 3. ビルドと書き込み
PlatformIOの「Build」ボタンを押してコンパイルを行い，「Upload」ボタンでデバイスにファームウェアを書き込む．

## 動作フロー

```text
起動
 ├─ SDカード・SCD41初期化処理
 ├─ 保存済みWi-Fi情報があるか
 │    └─ 自動接続を試みる
 │          ├─ 成功: 時刻同期後，SDから過去履歴をロードして【センサダッシュボード】へ遷移
 │          └─ 失敗: 自動で【メニュー画面】へ遷移
 └─ 保存情報なし
      └─ 【メニュー画面】へ移行
```

※ バックグラウンドでSD読み書き・グラフ集計処理が継続的に実行されるため，画面遷移中もデータ損失なく記録が行われる．
